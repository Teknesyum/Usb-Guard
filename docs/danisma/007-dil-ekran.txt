--- yardim: scanpc ---
                             [ Scan This PC ]
                             Scans this computer for worm remnants: running script
                             processes, Run/RunOnce, Winlogon, startup folders,
                             scheduled tasks, services, Defender exclusions and
                             Explorer sabotage. Findings are listed first; on your
                             confirmation the entries are deleted and the files are
                             moved to quarantine. A shallow scan, not a virus scan.
--- yardim: lang ---
                             [ Language / Dil  > ]
                             Changes the interface language: English or Turkish.
                             The choice is saved and not asked again.
--- yardim: fix ---
                             [ Fix  ->  {0} {1} ]
                             Cleans and guards the selected USB: stops the worm
                             process, deletes malicious shortcuts (subfolders too),
                             moves your hidden files back to the root, quarantines
                             the payload, then occupies the names the worm needs
                             with locked folders. Your files are never deleted; a
                             name clash gets a ' (2)' suffix.
--- yardim: wshoff ---
                             [ Turn The Script Engine Off  (.vbs / .js) ]
                             Turns Windows Script Host off (one registry value).
                             The .vbs / .js worms run through wscript.exe; with this
                             off, a clicked shortcut launches nothing.
                             Side effect: legitimate .vbs / .js scripts stop too (some
                             printer installers, corporate logon scripts, old setup
                             wizards). Reversible from the same menu.

--- yardim: wshoff ---
                             [ Betik Motorunu Kapat  (.vbs / .js) ]
                             Windows Script Host'u kapatır (tek kayıt değeri).
                             .vbs / .js solucanları wscript.exe ile çalışır; kapalıyken
                             kısayola tıklansa bile yük çalışmaz.
                             Yan etki: meşru .vbs / .js betikleri de durur (bazı yazıcı
                             kurulumları, kurumsal logon betikleri, eski kurulum
                             sihirbazları). Aynı menüden geri açılır.
