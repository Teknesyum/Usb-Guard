# UI Dönüşümü — 2026-09-27 (v1.29)

Usb-Guard bir konsol programıdır (cmd + Windows PowerShell 5.1); tek WinForms yüzeyi USB uyarı
penceresidir. Bu turda her yüzey sahibin düzenine (`ui-duzeni` + `benim` token'ları) taşındı:
renk, boyut ve etiket elle yazılmıyor, `src/build.ps1` kaymayı derlemede reddediyor.
